# AeroVision ✈️👁️

**AeroVision** is a Computer Vision project designed for object detection and tracking using YOLOv8 and ByteTrack.

---

## 📌 Features / المميزات
- **Object Detection:** Powered by YOLOv8 for precise detection (`yolov8n.pt`).
- **Object Tracking:** Integrated with ByteTrack for target tracking in video streams (`bytetrack_low.yaml`).
- **Video Analysis:** Includes sample execution and demo videos.
- **Presentation Included:** Comprehensive project presentation inside the `Presentation/` directory.

---
